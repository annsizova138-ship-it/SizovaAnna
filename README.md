# Эмулятор командной строки (вариант 20)

## 1. Общее описание

Учебный эмулятор языка оболочки ОС с графическим интерфейсом (tkinter).
Реализован этап 1 (REPL): окно с полем вывода и строкой ввода,
парсер команд и команды-заглушки.

## 2. Описание всех функций и настроек

- Заголовок окна содержит имя VFS (на этапе 1 это `default`).
- Парсер делит строку на слова (кавычки группируют слова с пробелами) и
  раскрывает переменные окружения реальной ОС: `$NAME` и `${NAME}`.
  `$HOME` работает и в Windows. Незаданная переменная заменяется пустой
  строкой.
- Команды:
  - `ls [аргументы...]` - заглушка, выводит своё имя и аргументы;
  - `cd [путь]` - заглушка, выводит своё имя и аргумент (не более
    одного);
  - `exit` - завершить работу.
- Ошибки выводятся строкой `Ошибка: ...`: неизвестная команда, неверное
  число аргументов, незакрытая кавычка.

## 3. Команды для сборки проекта и запуска тестов

Сборка не требуется. Нужен Python 3 с модулем tkinter (входит в
стандартную установку Python для Windows).

Запуск тестов (из корня репозитория):

```
# Windows
scripts\run_tests.bat

# Linux / macOS / Git Bash
PYTHONPATH=src python3 -m unittest discover tests
```

Запуск эмулятора: `python src/main.py` (в Windows также `run.bat`).

## 4. Примеры использования

Интерактивная сессия (значение `$HOME` зависит от компьютера):

```
$ ls -l /tmp
ls -l /tmp
$ cd docs
cd docs
$ ls $HOME
ls /home/user
$ cd a b
Ошибка: cd: неверное число аргументов
$ foo
Ошибка: foo: команда не найдена
$ ls "abc
Ошибка: незакрытая кавычка
$ exit
```
