# Эмулятор командной строки (вариант 20)

## 1. Общее описание

Учебный эмулятор языка оболочки ОС с графическим интерфейсом (tkinter).
Реализованы этап 1 (REPL), этап 2 (параметры запуска и стартовые
скрипты) и этап 3 (виртуальная файловая система из JSON). Все данные
VFS хранятся только в памяти, на диск ничего не распаковывается.

## 2. Описание всех функций и настроек

**Окно и парсер.** Заголовок окна содержит имя VFS. Парсер делит строку
на слова (кавычки группируют слова с пробелами) и раскрывает переменные
окружения реальной ОС: `$NAME` и `${NAME}`. `$HOME` работает и в
Windows. Незаданная переменная заменяется пустой строкой.

**Команды.**

| Команда | Описание |
|---|---|
| `ls [аргументы...]` | Заглушка: выводит своё имя и аргументы. |
| `cd [путь]` | Заглушка: выводит своё имя и аргумент (не более одного). |
| `vfs-info` | Служебная команда: имя VFS и SHA-256 её данных. |
| `exit` | Завершить работу. |

Ошибки выводятся строкой `Ошибка: ...`: неизвестная команда, неверное
число аргументов, незакрытая кавычка.

**Параметры командной строки.**

| Параметр | Описание |
|---|---|
| `--vfs ПУТЬ` | JSON-файл с VFS. Без параметра используется пустая VFS с именем `default`. |
| `--script ПУТЬ` | Стартовый скрипт. |

При запуске все параметры выводятся в консоль и в окно (отладочный
вывод).

**Стартовый скрипт** - текстовый файл, одна команда в строке. Команды
выполняются как при ручном вводе, на экране видны и ввод, и вывод. На
первой ошибке скрипт останавливается.

**Формат VFS (JSON).**

```json
{
  "name": "demo",
  "root": {
    "type": "dir",
    "children": {
      "hello.txt": {"type": "file", "encoding": "text",
                    "content": "Hello\n"},
      "data.bin": {"type": "file", "encoding": "base64",
                   "content": "AAEC/w=="},
      "docs": {"type": "dir", "children": {}}
    }
  }
}
```

- `name` - имя VFS (по умолчанию `default`);
- `root` - корневая папка (`"type": "dir"`), вложенные папки задаются
  словарём `children`;
- файл: `"type": "file"`, `encoding` - `text` (по умолчанию) или
  `base64` (двоичные данные), `content` - содержимое.

**Хеш в `vfs-info`.** SHA-256 считается от байтов загруженного
JSON-файла. Поэтому хеш изменится при любом изменении файла, в том числе
символов конца строки.

**Ошибки загрузки VFS** (файл не найден, неверный JSON, неверная
структура, неверный base64) выводятся в окне строкой
`Ошибка загрузки VFS: ...`. В этом случае используется пустая VFS, а
стартовый скрипт не выполняется.

**Файлы проекта.**

- `src/` - исходный код, `tests/` - тесты;
- `examples/` - VFS (`minimal.json`, `several_files.json`, `deep.json` с
  тремя уровнями папок, `broken.json` с ошибкой) и стартовые скрипты
  (`test_all.txt` проверяет все команды и заканчивается ошибкой,
  остальные `script_*.txt` показывают отдельные случаи);
- `scripts/` - скрипты ОС (Windows): `test_params.bat`,
  `test_scripts.bat`, `test_vfs.bat` (три варианта VFS),
  `test_vfs_errors.bat` (ошибки загрузки), `run_tests.bat`.

## 3. Команды для сборки проекта и запуска тестов

Сборка не требуется. Нужен Python 3 с модулем tkinter (входит в
стандартную установку Python для Windows).

Запуск тестов (из корня репозитория):

```
# Windows
scripts\run_tests.bat

# Linux / macOS / Git Bash
PYTHONPATH=src python3 -m unittest discover tests
```

Запуск эмулятора:

```
python src/main.py [--vfs ПУТЬ] [--script ПУТЬ]
```

## 4. Примеры использования

Запуск с VFS и стартовым скриптом (значение `$HOME` зависит от
компьютера):

```
python src/main.py --vfs examples/several_files.json --script examples/test_all.txt
```

```
Параметры запуска:
  vfs    = examples/several_files.json
  script = examples/test_all.txt
$ ls
ls
$ ls -l /tmp
ls -l /tmp
$ ls "my files" $HOME
ls my files /home/user
$ cd
cd
$ cd docs
cd docs
$ cd $HOME
cd /home/user
$ vfs-info
VFS: several
SHA-256: fa8de9e4fb698d4ac769cd462b16fc918fdba133260deffb9046182567717523
$ cd a b
Ошибка: cd: неверное число аргументов
Скрипт остановлен на строке 8
```

Ошибка загрузки VFS (`python src/main.py --vfs examples/broken.json`):

```
Параметры запуска:
  vfs    = examples/broken.json
  script = None
Ошибка загрузки VFS: неверный формат JSON: Expecting property name enclosed in double quotes: line 2 column 1 (char 46)
```
